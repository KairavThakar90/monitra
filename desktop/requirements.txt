# The GUI toolkit is pinned to one exact version. Left bare, the release job
# installed whatever was newest on the day: v1.3.2 (built 2026-10-09) and v1.3.3
# (2026-10-29) shipped Qt 6.12.0, published the day before the first of them,
# while everything had been verified on 6.11.2 -- and on 6.12 the Request
# dialog's time fields were drawn one pixel wide (ui/task_table.py has the fix,
# and tests/test_manual_time_entry_dialog.py reads the geometry back).
#
# Why 6.12.0 and not 6.11.2: the first 1.3.4 build (run 40878108382, 2026-10-29)
# pinned 6.11.2, and on BOTH macOS runners tests/test_layout_stability.py failed
# deterministically (23 cases, two attempts): on macOS the Activity panel's
# minimum width moved by 1-3 px with the length of the names in it. The same
# module, and the whole suite, had passed on every macOS and Windows run that
# used 6.12.0 (runs 40 and 41), and the full Windows suite with the time-field
# fix passes on 6.12.0 (4311 passed, 2026-10-29). So 6.12.0 is the toolkit every
# platform has been green on; 6.11.2 was only ever green on Windows. Move this
# pin on purpose: install the new version, run `python -m pytest tests/ -q`
# on it (and let CI run it on macOS), then change it. tests/test_dependency_pins.py
# fails on a bare line and on a PySide6 under test that is not this one.
PySide6==6.12.0
httpx
python-dotenv

# Keyboard/mouse event *counting* (background_services/activity/input_counter.py).
#
# Windows only, deliberately. pynput's macOS keyboard listener resolves every
# key to a character through Carbon's Text Services Manager, which on macOS 26
# asserts it is running on the main dispatch queue; from pynput's own listener
# thread that assertion raises SIGTRAP and kills the process outright. It is
# not catchable, and it killed Monitra the instant a timer was started.
#
# macOS counts events through a listen-only Quartz event tap instead
# (background_services/activity/mac_input_tap.py), which needs no extra
# dependency -- pyobjc-framework-Quartz below is already required -- and never
# decodes a key. Excluding pynput on macOS means the crashing code cannot be
# packaged into the .app at all, rather than merely going unused.
pynput; sys_platform != "darwin"

# Screenshot capture and processing (background_services/screenshot/).
# `mss` reads the primary display; Pillow resizes proportionally onto the
# 1000x1000 canvas and encodes WebP. Both are imported lazily, and an
# installation without them captures nothing and says so, rather than
# substituting a placeholder image.
mss
Pillow

# macOS-only: frontmost-application/window-title detection for app-usage
# and browser URL activity tracking (tracking/active_window.py). The
# `sys_platform` marker means `pip install -r requirements.txt` installs
# these on macOS and skips them entirely on Windows/Linux -- one
# requirements file for every platform, no separate per-OS file needed.
pyobjc-framework-Cocoa; sys_platform == "darwin"
pyobjc-framework-Quartz; sys_platform == "darwin"

# IANA timezone database. Windows ships no system tzdata, so ZoneInfo
# ("Asia/Kolkata") needs this package to resolve.
tzdata
